# 背景

课题组提供了一个服务器集群，包含 11 台服务器，我早早就在其上部署好了 k8s。虽然主要是用来做 GPU 相关工作的，但其他硬件资源其实也非常充足：

- CPU：2 x Intel Xeon Platinum 8558P，共计 96 核心 192 线程，主频 2.70 GHz
- 内存：32 × 64 GB DDR5，共计 2 TB
- 存储：4 × 7 TB NVMe Memblaze P6531DT
- 共享存储：101 TB GPFS 挂载
- 操作系统：Ubuntu 22.04.5 LTS

可以看出虽然 CPU 单核性能不算顶尖，但胜在数量众多，而且内存和存储等资源也非常够用；因此非常适合用来大规模并行跑中小型 RTL 设计的 EDA 综合仿真等流程。

对传统芯片设计工作流程来说这种特性基本上没什么用（没有团队会同时开发几万款芯片且需要一起跑仿真），但对于 Agentic EDA 来说是完美适配的：想要通过 Agentic RL 训练专用于芯片设计的 Agent，那么环境的 scale up 就是不可绕过的需求。

为此，把 EDA 工具链部署到 k8s 上来构建 Cloud Native EDA 集群是非常有必要的。
