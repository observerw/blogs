你好，这里是 [@observerw](https://github.com/observerw) 的个人博客。

这里记录我在工程实践、技术原理和阅读上的笔记。写得不一定都对，但尽量写清楚「为什么」。

## 关于本站

- 框架：[Astro](https://astro.build/) + [AstroPaper](https://github.com/satnaing/astro-paper)，样式基于 Tailwind CSS
- 内容：Markdown / MDX，内置文章列表、标签页与按时间归档
- 搜索：Pagefind 静态全文搜索
- 部署：GitHub Actions → GitHub Pages
- 源码：[observerw/blogs](https://github.com/observerw/blogs)，欢迎通过 [RSS](/blogs/rss.xml) 订阅
